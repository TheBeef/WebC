This is some examples of using WebC with the Mongoose web server.

# Setup
To compile you need to download and copy the mongoose.c and mongoose.h file from the
Mongoose project (https://github.com/cesanta/mongoose) and put them in this directory.

You also need to have gcc and make installed.  As well as the webcc pre-compiler in the path.

## Compiling
To compile just run the makefile in the example directory

### Linux
cd HelloWorld
make -s

# Web server
When you run an example you can goto localhost:8080 to see the web page.
